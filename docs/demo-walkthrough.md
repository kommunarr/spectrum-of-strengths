# Two-minute technical walkthrough

Use this as a recording script or a live demo for a software engineering
portfolio. It shows implemented behaviour and avoids claims about future
programs or organizational recognition. Open the [English home page](https://kommunarr.github.io/spectrum-of-strengths/)
and the [repository README](../README.md) in separate tabs before starting.

| Time | Show | Say |
| --- | --- | --- |
| 0:00–0:20 | English Home introduction and first value card. | “This is a bilingual public record for Spectrum of Strengths. The first release explains its four value ideas and links to a dated archive.” |
| 0:20–0:40 | Let the value card advance, then use pause and a direction control. | “The carousel runs on its own, but visitors can control it. It also stops on keyboard focus and respects reduced-motion settings.” |
| 0:40–1:00 | Select **Français**; show the French Home and navigation. | “Each published page has its own French or English URL, with localized content and metadata.” |
| 1:00–1:22 | Open **Archives et journal**, then the dated opening entry; copy or show its direct URL. | “Entries have permanent links in both languages. The date and status distinguish an approved public record from future plans.” |
| 1:22–1:42 | Use the keyboard to move focus through a link or control, then show the narrow mobile layout if recording permits. | “The interaction and layout were checked for keyboard use, mobile reflow, and accessible names. The site's accessibility review also included a manual pass.” |
| 1:42–2:00 | Switch to the repository README, then point to the [case study](engineering-case-study.md) and [performance baseline](performance-baseline.md). | “The build generates direct route HTML, and CI checks translations, routes, browsers, accessibility, and representative Lighthouse pages. The linked case study shows the code and testing evidence.” |

For a recording, capture the site at readable zoom and keep browser controls
visible when showing URLs or keyboard focus. Pause long enough for the value
card to advance once; shorten another segment if needed. The [desktop](screenshots/home-desktop.png)
and [French mobile](screenshots/home-mobile-fr.png) screenshots are available
for a slide or portfolio page. Do not describe the Lighthouse lab scores as
real-user measurements or an accessibility certification.
